# 小小车库 · 3D 汽车工坊

十种车型的触屏三维拆解和拼装游戏。公开试玩：
https://fattoliu.github.io/dino-island/car-workshop/

## 玩法

- 每次打开或换车，所有可拆部件默认放在车身两侧的车库地面，只有底盘留在工位。
- 在三维场景中直接拖住零件，移到发光位置附近松手即可装好。也可以点零件或下方零件按钮，再点「装上」。
- 轻点装好的部件，选择「拆下」，可以单独拆卸。左下「拆开」重新开始。
- 单指拖空白位置绕车旋转；双指同向移动平移，捏合缩放。电脑可右键拖动平移、滚轮缩放、方向键移动视角。
- 左上打开车型车库；全部拼好后可让汽车在车间内行驶。
- 声音默认关闭，没有登录、广告、计时、处罚、追踪或联网素材。

## 车型与模型范围

奔驰 G 级外形参考、丰田兰德酷路泽外形参考、宝马赛车外形参考、法拉利赛车外形参考、重型卡车、消防车、警车、出租车、吊车、履带挖掘机。每辆车有 13–17 个独立可拆部件，包括相应的备胎、行李架、尾翼、消防云梯/水管、吊臂/支腿、履带/挖斗等。

模型和车库全部为原创程序几何，不使用第三方汽车模型或品牌标识。它们是用于儿童拼装的车型外形参考，不是品牌官方模型、精确机械图纸、车辆数字孪生或维修教学。车型名称仅用于说明外形灵感。

## 技术

纯静态 HTML / CSS / ES modules，Three.js 0.171.0 随项目分发，无运行时 CDN。正常路径使用 WebGL 2、PBR 金属/玻璃材质、环境反射、ACES 色调映射、动态阴影。车库和零件按材质合批，车型约 43–86 个 mesh，控制移动设备开销。

GPU/WebGL 不可用时，页面明确显示「兼容画质」，使用相同几何、相机与拾取逻辑的 CPU 三角形光栅化。兼容模式保留真正的三维拼装交互，但不等同于 WebGL 的材质、阴影和帧率。

## 运行与测试

使用支持 WebGL 2 的现代 iPad Safari、Chrome 或 Edge，通过 HTTP 服务打开，不支持 file:// 双击打开模块。

```sh
python3 -m http.server 8080
npm test
```

测试覆盖十种模型几何、零件唯一性与数量、全部默认拆开、完整拼装/拆卸/重置循环、重复和无效操作、吸附阈值。无打包步骤。第三方依赖 Three.js 的 MIT 许可见 `vendor/THREE-LICENSE.txt`。模型与场景代码是本项目原创。
