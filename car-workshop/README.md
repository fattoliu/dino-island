# 小小车库 · 阳光小镇

原创的硬朗微缩汽车三维拼装游戏。公开试玩：
https://fattoliu.github.io/dino-island/car-workshop/

## 拼装、收藏、换装

- 汽车模板库有 **22 款车型**，覆盖越野车、轿车、赛车、救援车、巴士、货运车、工程车和旅行车。不是所有汽车品牌或所有车系的完整目录。
- 模板可反复使用。每次选模板，都从默认涂装、全部散开的零件开始，不会消耗或锁定模板。
- 每辆车有 13–18 个独立可拆组件。可直接拖动三维零件，或点零件按钮，再点小手指向的位置安装。选中零件轻轻浮动，视角平滑转向安装位置；拖动空白处随时接管视角。
- 点已经装上的零件可以拆下；「拆开」开始新一次拼装，已完成的收藏车保留。
- 拼好后自动成为一辆独立收藏车，同车型同涂装也能收藏多辆。每个模板提供 3–4 种适配涂装；换装会改变实际模型，不只是色块。
- 「停车场」显示所有收藏车，可以查看、换涂装、开出去或再拼一辆。进入小镇时，实体停车区展示最近的其他收藏车（标准画质最多 6 辆、兼容画质最多 3 辆），完整收藏仍在停车场列表里。
- 收藏使用当前浏览器的 localStorage，刷新后保留；**不跨浏览器或设备同步**。清除网站数据、隐私模式或存储限制可能影响保存。保存失败会显示提示；损坏的旧存档不会被静默覆盖。

## 开进阳光小镇

这是可自由转向的小型三维玩具城镇，包含医院、警局、学校、商店、公园、施工区、农场、营地和赛车场。不是只有一条固定公路，也不是大型开放世界或精确汽车物理模拟。

- 一个大摇杆控制驾驶：上推前进，下推倒车，左右转向，斜推可同时开车和转向；力度随距离变化，松手回正并自动减速停车。没有独立油门、倒车或刹车按钮。电脑支持方向键 / WASD、空格刹车、R 倒车、E 执行任务。
- 导航图上蓝箭头是汽车，黄点是当前目标；场景中也有黄色标记。
- 一般任务需要到达地点、停稳，再按住对应行动按钮。任务会改变场景里的物件，并显示完成反馈。
- 赛车在起点准备后开始计时，后续检查点驶过即算通过，不需要停车按按钮。赛道有两辆示范赛车；记录本次小镇游玩中的最好时间，不是联网竞技排行榜。
- 完成后可继续探索、重玩，或随时「回停车场」。驶出和返回不会丢失收藏车辆。

### 车型与可玩任务

| 车型 | 任务 |
| --- | --- |
| 方盒子大G、探险越野车 | 山野路线、领取装备与营地补给 |
| 蓝色运动赛车、流线超级跑车 | 赛车场连续检查点、计时一圈 |
| 120救护车 | 公园接上需要帮助的小伙伴，送到医院 |
| 云梯消防车 | 连接水管、喷水熄灭小屋旁火苗 |
| 110巡逻警车 | 追踪标记小车，友善拦停，陪同返回警局 |
| 出租车、公交、校车、接驳小巴 | 不同站点接人和送达 |
| 大卡车、快递小货车、皮卡 | 装货、快递或农产品运输 |
| 吊车、挖掘机、搅拌车 | 吊起横梁、清理碎石、浇筑路面 |
| 清洁车 | 收集垃圾并分类回收 |
| 拖拉机 | 分区收获蔬菜，送到农场货台 |
| 露营车 | 到营地展开遮阳棚、布置营地 |
| 冰淇淋车 | 在公园和营地制作、分享冰淇淋 |
| 糖果小轿车 | 领取野餐篮、到公园野餐 |

每辆车都有预设的、可重玩的任务链；部分同类车辆共享玩法。不是无限随机任务系统。人物和救援情节采用友善玩具表现，没有真实伤情或暴力。

## 视觉与声音

- 所有汽车、城镇、车库、手势提示均为本项目原创几何或矢量图形。色彩与轮廓受到可爱车辆表情的启发，没有复制 Apple 表情图稿或官方车辆模型。
- 警车的 110、救护车的 120、出租车的 TAXI 是模型几何字样，兼容画质也能显示。
- 恢复原来十款车型的硬朗车身、轮辋、格栅与细节；另外十二款车型使用小倒角保留清楚的大平面。深色玻璃、轮胎和更饱满的车漆形成对比。提供键盘焦点、可读标签、较大按钮，并尊重减少动态效果设置。未作儿童心理学或临床效果验证。
- 首次触摸/键盘交互后播放原创程序音乐，保留拼装音效和欢呼掌声。八种发动机音色覆盖 22 车型；警车为快速扫频警笛、救护车为双音交替、消防车为低速长扫频。应急车驶入小镇时默认开警笛，可独立关闭；总静音控制所有声音，切后台暂停。声音是游戏合成表现，不是实际车辆录音。
- 无登录、广告、追踪或运行时外部素材请求。

## 技术与验证

纯静态 HTML / CSS / ES Modules，随项目分发 Three.js 0.171.0，无打包步骤。WebGL 2 路径使用 PBR 材质、适度环境反射、Neutral 色调映射及方向性灯光。小镇建筑可投影，太阳阴影跟随车辆；WebGL 不可用时明确显示「兼容画质」，采用相同三维几何和拾取逻辑的 CPU 光栅化，材质、阴影与帧率会不同。

本地运行：在仓库目录用 `python3 -m http.server 8080`，浏览器访问 `/car-workshop/`。测试在本目录运行 `npm test`。测试覆盖模型与涂装、拼装、独立收藏与异常存储、22 车型任务、自由驾驶与倒车、赛道检查点、音频生命周期和界面引用。实际复查范围与限制见 QA.md。

仅更新 `car-workshop/`。原恐龙游戏根入口和 `dist/` 保持原样。Three.js MIT 许可见 vendor/THREE-LICENSE.txt。
